# Changelog

## 0.0.4

- Added clear semantic git file change indicators: green for added/untracked, blue (`#569cd6`) for modified, red for deleted, orange for conflicting.
- Added editor gutter, overview ruler, minimap gutter, and diff editor colors for git changes.
- Fixed terminal ANSI colors: green was mapped to blue, yellow to pink, and several normal/bright pairs were identical. All 16 slots are now semantically correct and visually distinct.
- Synced Ghostty, iTerm2, and Warp terminal themes to match the updated palette.

## 0.0.3

- Added extension icon asset with Bento palette styling.

## 0.0.1
