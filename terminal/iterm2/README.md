# Bento For iTerm2

This folder contains an iTerm2 color preset inspired by Monkeytype's `bento` theme.

## Source

The base colors are inspired by Monkeytype's `bento` theme in:

- `https://github.com/monkeytypegame/monkeytype.git`
- `/frontend/src/ts/constants/themes.ts`

## Files

- `Bento.itermcolors`: iTerm2 color preset

## Install

1. Open iTerm2.
2. Go to Settings -> Profiles -> Colors.
3. Click `Color Presets...`.
4. Click `Import...` and select `Bento.itermcolors`.
5. Choose the imported `Bento` preset.
